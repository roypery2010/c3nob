# c3nob 🛠️

`c3nob` is a lightweight, C3-native, dependency-free build system script designed to provide a clean, programmatic alternative for managing C3 projects.

## Getting Started

- Configure: `c3c compile-run build.c3 c3nob.c3 configure`
- Debug Build & Run: `c3c compile-run build.c3 c3nob.c3 debug`
- Release Build & Run: `c3c compile-run build.c3 c3nob.c3 release`
- Clean: `c3c compile-run build.c3 c3nob.c3 clean`
